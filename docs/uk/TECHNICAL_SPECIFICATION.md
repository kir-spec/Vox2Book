# 8 редакційних аудитів (універсально)

Профілі формату: `prompts/uk/profiles/`.  
Імена: `config/glossary_user.json`.

1. **Орфографія** — правопис, частки, вводні  
2. **Пунктуація** — коми, «лапки», тире ` — `  
3. **Синтаксис** — великі літери, кінцеві знаки, завершені речення  
4. **Факти** — однакові власні назви; не змінювати числа/дати  
5. **Стиль** — голос автора; прибрати лише машинний сміття  
6. **Лексика** — заїкання, дублі, явні STT-виправлення  
7. **Структура / check_cuts** — без обривів на сполучниках  
8. **Атрибуція** (кілька спікерів) — узгоджені імена та рід, якщо відомо  

STT: `prompts/uk/profiles/SPEECH_TO_TEXT.md` · Діалоги: `prompts/uk/profiles/DIALOGUE_TRANSCRIPT.md`
