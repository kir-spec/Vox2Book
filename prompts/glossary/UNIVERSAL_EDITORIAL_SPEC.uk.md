## 0. Призначення

Документ фіксує **вимоги замовника до якості** та **типові помилки автоматики** на реальних правках.  
Єдине ТЗ для ШІ-редактора, ручної вичитки та regex-скриптів.

**Імена, бренди й топоніми проєкту** — лише з `config/glossary_user.json`, не з прикладів нижче.

## 1. Контекст і зміст (обов’язково)

| ID | Вимога |
|----|--------|
| **C-01** | Перед нетривіальною правкою STT — **не менше 10 реплік ДО і 10 ПІСЛЯ** цільового фрагмента. |
| **C-02** | Перевіряти зв’язку **питання ↔ відповідь** і тему в вікні ±10 реплік. |
| **C-03** | **Реставрація за змістом:** не залишати безглуздих оборотів; не втрачати фрази при перезбірці. |
| **C-04** | За 2+ правдоподібних читання — **не правити мовчки**; позначка `[?]` або питання замовнику. |
| **C-05** | Великі документи (300+ стор.): **100% покриття** без пропусків реплік. |
| **C-06** | Заборонені глобальні `replace()` по файлу для омофонів, брендів, мату. |

## 2. Паузи STT: крапка й велика літера всередині фрази

| ID | Проблема | Дія |
|----|----------|-----|
| **P-01** | Пауза Whisper розриває одну думку: `, що. Значить` | → `, що значить` |
| **P-02** | Те саме після `тому що`, `щоб`, `оскільки` | Крапка + велика → пробіл + мала, якщо думка не завершена |
| **P-03** | Зворотна помилка: склеїли **самостійні** речення комою | Відновити **крапку** (див. §3) |

**Заборонений regex (ніколи):**

```text
([а-яіїєґ]{3,})\.\s+([а-яіїєґ])  →  \1, \2
```

## 3. Comma splices (склейка незалежних речень)

| ID | Помилка автоматики | Правильно |
|----|--------------------|-----------|
| **S-01** | `важко, якщо ти не проти, я хотів би…` | `важко. Якщо ти не проти, я хотів би…` |
| **S-02** | `сприйняття, якщо продовжити тему…` | `сприйняття. Якщо продовжити тему…` |
| **S-03** | `у пам’яті, якщо такого відбитка немає…` | `у пам’яті. Якщо такого відбитка немає…` |
| **S-04** | `побачити, але якщо…` | **Залишити** `побачити. Але якщо…` |

**Стартери нового речення** — крапка **не** стає комою:  
`Але`, `А`, `І`, `Тому`, `Однак`, `До речі`, `Слухай`, `Дивись`, `Ось`, `Ну`, `Значить`, `Якщо`, `Коли`, `Взагалі`, `Коротше`.

**Пастка regex:** `но.\s+Якщо` хибно спрацьовує на `складно. Якщо` — використовувати **межу слова** `\bно\.\s+Якщо`.

## 4. Інтонаційні коми (зайві паузи STT)

| ID | Прибрати | Приклад |
|----|----------|---------|
| **I-01** | Кома перед `щось` / `чогось` **після дієслова** | `знайти, щось` → `знайти щось` |
| **I-02** | Кома всередині займенника | `записую на, щось` → `записую на щось` |
| **I-03** | Кома в простому питанні | `А ти, коли лягаєш…` → `А ти коли лягаєш…` |

| ID | **Не чіпати** | Приклад | Причина |
|----|---------------|---------|---------|
| **I-10** | Оцінка числа | `340, щось гривень` | Розмовна невизначеність |
| **I-11** | Законне підрядне | `я знаю, що він прийде` | Нормальна пунктуація |

## 5. Пунктуація довгих монологів

| ID | Вимога |
|----|--------|
| **M-01** | Голосове **> 1200–1500 символів** з малою кількістю крапок — **додати** межі між завершеними думками. |
| **M-02** | Маркери нової думки (обережно): `Слухай`, `Дивись`, `До речі`, `Тому`, `Значить`, `Уявіть` — лише якщо перед ними немає крапки. |
| **M-03** | **Не** вставляти крапки перед кожним `ось`, `ну`, `просто` у коротких репліках. |
| **M-04** | **Не** використовувати `це` як універсальний маркер межі. |
| **M-05** | Після автопунктуації — **ручна вичитка** найдовших реплік; нормалізувати `,.` → `.`, `..` → `.`. |
| **M-06** | Орієнтир **~1 крапка на 200–280 символів** у довгому монологі. |

## 6. STT-ослишки (лише whitelist + контекст)

Заміни **лише за повного збігу фрази** та перевірки ±10 реплік.

### 6.1. Техніка й мережа

| Клас | Типовий збій | Відновлення |
|------|--------------|-------------|
| VPN | `віпен`, `віпеон`, `не у віпі` | `VPN` |
| USB | спотворення Type-C / micro USB | `Type-C`, `micro USB` |
| Мережа | спотворення ByeDPI | `ByeDPI` |
| DAW | `Logic"ом` | `Logic Pro` |

### 6.2. Числа в мовленні

| ID | Проблема | Дія |
|----|----------|-----|
| **N-01** | STT підставив цифру замість слова | за контекстом (`22` → `два`) |
| **N-02** | Зайвий пробіл у дробі | `3, 8 мільйона` → `3,8 мільйона` |
| **N-03** | Множник | `1,5×` |
| **N-04** | Одиниці швидкості | `20 км/год` |

## 8. Мат і правовий статус

| Режим | Умова | Дія |
|-------|-------|-----|
| **За замовчуванням** | діалог / STT | `keep_mat=True` — **не цензурувати** |
| Цензура | «прибери мат», «без 18+» | літературна заміна + звіт |
| Друк з матом | явна команда | зберегти лексику + **нагадати** про маркування 18+ |

## 9. Два режими діалогу

| Режим | Коли | Мітки експорту | Формат реплік |
|-------|------|----------------|---------------|
| **`raw_chat`** | архів, екран | **Зберігати** `Спікер [ГГ:ХХ] [Голосове]:` | як у експорті |
| **`prepress_book`** | «книга», «для друку» | **Прибрати** час, `[Голосове]`/`[Текст]` | `— Текст репліки. — Спікер.` |
