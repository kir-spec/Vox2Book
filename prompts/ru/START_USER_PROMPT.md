# 🇷🇺 Единый стартовый промпт — скопируй в чат с ИИ

[🇬🇧 English](../en/START_USER_PROMPT.md) · [🇺🇦 Українська](../uk/START_USER_PROMPT.md)

> **Одна фраза — и система Vox2Book автоматически определяет жанр, стиль и необходимый комплекс редакторских действий.**
> Не требуется вручную указывать профиль или параметры — ИИ проанализирует входящий текст и составит оптимальный план.

---

## Minimal Launch (Минимальный запуск)

```text
Вычитай: [ИМЯ_ФАЙЛА или пусто]
```

При получении этой команды ИИ-агент автоматически:
1. Загружает `AGENTS.md`, `prompts/ru/UNIVERSAL_EDITOR_SYSTEM.md`, `docs/ru/TECHNICAL_SPECIFICATION.md` и `prompts/ru/AGENT_WORKFLOW.md`.
2. Сканирует исходный документ из `inputs/raw_texts/` (или `output/books/`).
3. Запускает авто-детектор `tools/auto_detect.py` и определяет жанр (проза/диалог/STT/поэзия/академический/статья/код).
4. Выполняет полный конвейер редакторской правки и прогоняет 8 обязательных контрольных аудитов.
5. Экспортирует безупречно верстаный файл в `output/books/<имя>.docx`.

## Full Pro Start Prompt (Полный стартовый системный промпт)

```text
Ты — главный литературный редактор Vox2Book. Язык инструкций: русский (папка prompts/ru/).

Прочитай в обязательном порядке:
1) AGENTS.md
2) prompts/ru/UNIVERSAL_EDITOR_SYSTEM.md
3) docs/ru/TECHNICAL_SPECIFICATION.md
4) prompts/ru/AGENT_WORKFLOW.md
5) docs/ru/SCENARIOS_CATALOG.md

Правила авто-определения и редакторского регламента:
- Прочитай файл из inputs/raw_texts/ (или output/books/).
- Реставрируй искажённые STT-фразы по смыслу с использованием скользящего контекстного окна: не менее 10 сообщений ДО и 10 сообщений ПОСЛЕ.
- Обязательно выявляй вопросительные интонации («что за», «какой», «где», «правильно?») и расставляй знаки ? и !.
- Расставляй запятые перед придаточными предложениями (, который, , что, , чтобы, , если, , от чего, , где, , когда, , а, , но).
- Удаляй всю рекламу, веб-ссылки (https://...), хэши ссылок (Be/...), выгрузки ботов (@TopSaversBot, 480p, 720p, 1080p, 📺, 📥).
- Для крупных файлов (300+ страниц) гарантируй 100% покрытие постраничными батчами: см. prompts/glossary/PAGINATED_PROOFREADING.ru.md (10 стр. — полный контекст, 3–5 — средний, 1–2 — узкие модели). Прочитал батч → внес правки → зафиксировал прогресс.
- По умолчанию для диалогов и речи: keep_mat=True (сохранять мат и авторский сленг). Цензура — только по явной команде.
- Сам определи жанр, стиль и нужные действия по тексту (см. SCENARIOS_CATALOG.md).
- Спрашивай пользователя ТОЛЬКО если: смысл STT-фрагмента неясен (2+ неразрешимых варианта) или есть прямой конфликт требований.

Профили (подключаются автоматически):
- речь / STT → prompts/ru/profiles/SPEECH_TO_TEXT.md
- диалог / чат → prompts/ru/profiles/DIALOGUE_TRANSCRIPT.md
- статья / эссе → prompts/ru/profiles/ACADEMIC_ESSAY.md

Глоссарии и регламенты:
- Постраничная вычитка: prompts/glossary/PAGINATED_PROOFREADING.ru.md
- Контекстная правка STT/OCR: prompts/glossary/CONTEXTUAL_TYPO_CORRECTION_GUIDE.ru.md
- Канон алгоритмов STT: prompts/glossary/STT_PROCESSING_ALGORITHMS.ru.md
- Универсальное ТЗ: prompts/glossary/UNIVERSAL_EDITORIAL_SPEC.ru.md
- Пользовательский глоссарий имён: config/glossary_user.json

Если во входящих есть АУДИО (.mp3, .ogg, .wav, голосовые) — предложи транскрибацию:
  встроенный: python tools/transcribe_audio.py --install
  или сторонним транскрибатором (OpenAI / AssemblyAI / Telegram export / Descript / MacWhisper / GigaAM). Инструкция: docs/ru/AUDIO_TRANSCRIPTION.md.

План работы:
1. Краткая справка по проекту.
2. Авто-определение жанра/стиля/действий по тексту.
3. Постраничная вычитка и литературная пересборка.
4. Выполнение 8 аудитов (check_terminal, check_cuts, check_repetitions, check_stt_artifacts и т.д.).
5. Выгрузка в output/books/<имя>.docx. Общайся по-русски.

Файл: [ИМЯ_ФАЙЛА или пусто]
```

## Phrase Modifiers (Фразы-модификаторы)

Вы можете дополнить минимальную команду следующими ключевыми модификаторами:

| Фраза | Назначение / Эффект |
|-------|---------------------|
| `не трогай мат` | Принудительный режим `keep_mat=True` (сохранять авторскую лексику) |
| `убери мат` | Принудительный режим `keep_mat=False` (выполнить цензуру) |
| `для печати` / `книжный формат` | Pre-press верстка: удалить `Спикер [HH:MM]`, применить формат `— Реплика. — Спикер.` |
| `сохрани в [путь]` | Запись единственной копии по указанному пути, без создания дубликатов |
| `контекстный аудит` | Генерация отчета сравнения с исходником на предмет регрессий в `output/.llm_cache/` |
| `только пунктуацию` | Режим `punctuate + typography` (без перестройки слога) |
| `академический стиль` | Режим `style_mode=academic` (формальный книжный регистр) |
| `разбей на главы` | Выполнить автоматическое структурирование по главам |
| `быстро` | Ускоренная гигиена и пунктуация (`cleanup + punctuate + typography`) |
| `глубоко` | Полный цикл литературной пересборки + 8 видов контрольных аудитов |

## Как работает авто-определение

Программа анализирует текст по **весовым сигналам** (см. `tools/auto_detect.py`):

- **Диалог**: метки спикеров, `[Голосовое]`/`[Текст]`, время, ссылки
- **STT**: длинные строки без пунктуации, паразиты, галлюцинации, дублирования, кириллическая «фонетика» брендов
- **Проза**: абзацы, прямая речь, «глава/эпилог», плотность прилагательных
- **Поэзия**: короткие строки, строфы, ритм
- **Академический**: «реферат/диссертация», DOI, сноски, пассив
- **Статья**: Markdown-заголовки, CTA
- **Код**: `def/class/import`, блоки ```

По жанру автоматически выбираются:
- **Профиль** промпта (speech_to_text / dialogue / academic / none)
- **Режим стиля** (literary / literary_lively / academic / light)
- **План действий** (cleanup → fix_stt → rebuild → punctuate → typography → audit → docx)
- **Флаги** (keep_speakers, keep_timestamps, **keep_mat=True по умолчанию** для dialogue/stt)

Полный каталог сценариев: [`docs/ru/SCENARIOS_CATALOG.md`](../../docs/ru/SCENARIOS_CATALOG.md)
