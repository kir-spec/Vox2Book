# 🇷🇺 Единый стартовый промпт — скопируй в чат с ИИ

[🇬🇧 English](../en/START_USER_PROMPT.md) · [🇺🇦 Українська](../uk/START_USER_PROMPT.md)

> **Одна фраза — и программа сама определит жанр, стиль и нужные действия.**
> Не нужно указывать жанр, режим или профиль вручную — ИИ проанализирует текст и выберет план.

---

## Минимальный запуск (одна фраза)

```text
Вычитай: [ИМЯ_ФАЙЛА или пусто]
```

Этого достаточно. Программа:
1. Прочитает `AGENTS.md`, `prompts/ru/UNIVERSAL_EDITOR_SYSTEM.md`, `docs/ru/TECHNICAL_SPECIFICATION.md`.
2. Откроет файл из `inputs/raw_texts/` (или `output/books/`).
3. **Сама определит** жанр (проза/диалог/STT/поэзия/академический/статья/код), стиль и план действий.
4. Выполнит все нужные правки и аудиты.
5. Сохранит результат в `output/books/<имя>.docx`.

## Полный стартовый промпт (для ИИ-агента)

```text
Ты — литературный редактор Vox2Book. Язык инструкций: русский (папка prompts/ru/).

Прочитай:
1) AGENTS.md
2) prompts/ru/UNIVERSAL_EDITOR_SYSTEM.md
3) docs/ru/TECHNICAL_SPECIFICATION.md
4) prompts/ru/AGENT_WORKFLOW.md
5) docs/ru/SCENARIOS_CATALOG.md

Авто-определение и Обязательные правила:
- Прочитай файл из inputs/raw_texts/ (или output/books/).
- Реставрируй нелепые STT-фразы по смыслу с использованием скользящего окна контекста: **не менее 10 сообщений ДО и 10 сообщений ПОСЛЕ**.
- **Обязательно выявляй вопросительные интонации и ставь знаки (`?`, `!`)**, разбивая сплошной устный поток на законченные предложения.
- **Расставляй запятые перед придаточными предложениями** (*, который*, *, что*, *, чтобы*, *, если*, *, от чего*, *, где*, *, когда*, *, а*, *, но*).
- **Удаляй всю рекламу, веб-ссылки (`https://...`), выгрузки ботов (`@TopSaversBot`, `480p`, `720p`, `1080p`, `📺`, `📥`)**.
- При обработке больших файлов (300+ страниц) **гарантируй 100% обработку всех страниц и реплик**.
- Сам определи жанр, стиль и нужные действия по тексту (см. SCENARIOS_CATALOG.md).
- Не спрашивай жанр/стиль/профиль — определи их сам по признакам текста.
- Спрашивай только если: смысл STT-фрагмента неясен (2+ варианта) или
  есть конфликт (например, «убери мат» + текст с матом и нет явного запрета).

Профили (подключаются автоматически по жанру):
- речь/STT → prompts/ru/profiles/SPEECH_TO_TEXT.md
- диалог/чат → prompts/ru/profiles/DIALOGUE_TRANSCRIPT.md
- статья/эссе → prompts/ru/profiles/ACADEMIC_ESSAY.md

Глоссарий: config/glossary_user.json
Контекстная правка STT/OCR: prompts/glossary/CONTEXTUAL_TYPO_CORRECTION_GUIDE.ru.md
Канон алгоритмов STT: prompts/glossary/STT_PROCESSING_ALGORITHMS.ru.md
Универсальное ТЗ: prompts/glossary/UNIVERSAL_EDITORIAL_SPEC.ru.md

Если у меня АУДИО (.mp3, .ogg, голосовые) — предложи транскрибацию:
  встроенный: python tools/transcribe_audio.py --install
  или OpenAI API / AssemblyAI / экспорт Telegram / Descript / MacWhisper / GigaAM …
  (инструкция: docs/ru/AUDIO_TRANSCRIPTION.md), затем вычитку из inputs/raw_texts/.

1. Краткая справка по проекту.
2. Прочитай файл.
3. Определи жанр/стиль/действия (не спрашивай — определи сам).
4. Выполни все нужные правки и 8 аудитов.
5. Результат — output/books/. Общайся по-русски.

Файл: [ИМЯ или пусто]
```

## Фразы-модификаторы (можно добавить к основной фразе)

> Необязательно. Программа работает и без них. Добавь, если хочешь переопределить.

| Фраза | Эффект |
|-------|--------|
| `не трогай мат` | Принудительно keep_mat=True (**по умолчанию для диалогов**) |
| `убери мат` | Принудительно keep_mat=False (цензура) |
| `для печати` / `допечатка` / `книжный формат` | prepress_book: убрать `Спикер [ЧЧ:ММ]`, формат `— реплика. — Спикер.`, «ёлочки», `—` |
| `сохрани в [путь]` | единственная копия по указанному пути, без дубликата в `output/books/` |
| `контекстный аудит` | Сравнение с исходником, отчёт регрессий STT |
| `только пунктуацию` | Только punctuate + typography |
| `убери мусор` | cleanup + remove_garbage + fix_repetitions |
| `сохрани стиль автора` | Минимум rebuild, literary_lively |
| `академический стиль` | style_mode=academic |
| `разбей на главы` | split_chapters |
| `сделай красиво` | Все действия + typography + docx |
| `быстро` | cleanup + punctuate + typography |
| `глубоко` | Все действия + полный аудит |
| `не меняй слова` | punctuate + typography только |
| `восстанови бренды` | restore_brands |
| `убери повторы` | fix_repetitions |
| `проверь обрывы` | fix_terminal + check_cuts |

## Как работает авто-определение

Программа анализирует текст по **весовым сигналам** (см. `tools/auto_detect.py`):

- **Диалог**: метки спикеров, `[Голосовое]`/`[Текст]`, время, ссылки
- **STT**: длинные строки без пунктуации, паразиты, галлюцинации, дублирования, кириллическая «фонетика» брендов
- **Проза**: абзацы, прямая речь, «глава/эпилог», плотность прилагательных
- **Поэзия**: короткие строки, строфы, ритм
- **Академический**: «реферат/диссертация», DOI, сноски, пассив
- **Статья**: Markdown-заголовки, CTA
- **Код**: `def/class/import`, блоки ```

По жанру автоматически выбираются:
- **Профиль** промпта (speech_to_text / dialogue / academic / none)
- **Режим стиля** (literary / literary_lively / academic / light)
- **План действий** (cleanup → fix_stt → rebuild → punctuate → typography → audit → docx)
- **Флаги** (keep_speakers, keep_timestamps, **keep_mat=True по умолчанию** для dialogue/stt)
