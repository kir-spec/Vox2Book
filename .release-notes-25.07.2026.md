## Vox2Book 25.07.2026 — universal STT editorial spec

### Highlights

- **New:** [`UNIVERSAL_EDITORIAL_SPEC`](prompts/glossary/UNIVERSAL_EDITORIAL_SPEC.en.md) — depersonalized client requirements (context ±10 turns, comma splices, long monologues, numbers/units, tail hallucinations, `keep_mat`, `raw_chat` / `prepress_book`).
- **New:** [`STT_PROCESSING_ALGORITHMS`](prompts/glossary/STT_PROCESSING_ALGORITHMS.en.md) — canon for forbidden regex, whitelist STT fixes, pre-press, audit checklist.
- **Updated:** all trilingual prompts (`prompts/en/`, `prompts/ru/`, `prompts/uk/`) — workflows, dialogue/speech profiles, START prompts, `AGENTS.md`.

### Quick start

1. Open repo in Cursor / VS Code
2. `inputs/raw_texts/` — or `inputs/audio/` → `python tools/transcribe_audio.py --install`
3. Copy `prompts/en/START_USER_PROMPT.md` into AI chat
4. Result: `output/books/*.docx` (or path you specify)
