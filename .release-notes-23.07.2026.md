## Vox2Book — publishing kit for AI assistants

Prompts, editorial rules, and scripts that turn **raw text** into a **formatted DOCX manuscript**.

### What's included

- Trilingual prompts: `prompts/en/`, `prompts/ru/`, `prompts/uk/`
- Contextual STT typo guides (fix in sentence context, not global replace)
- Audio → text: `tools/transcribe_audio.py` + docs for Whisper, OpenAI API, AssemblyAI, Deepgram, Telegram, Descript, GigaAM, Vosk, and more
- Works with any AI: Cursor, VS Code, LM Studio, Ollama, OpenAI, Claude

### Quick start

1. Open repo in Cursor / VS Code
2. `inputs/raw_texts/` — or `inputs/audio/` → `python tools/transcribe_audio.py --install`
3. Copy `prompts/en/START_USER_PROMPT.md` into AI chat
4. Result: `output/books/*.docx`

## Vox2Book — издательский комплект для нейросетей

Промпты, правила вычитки и скрипты, которые превращают **сырой текст** в **оформленный рукописный DOCX**.

### Что входит

- Промпты на трёх языках: `prompts/ru/`, `prompts/en/`, `prompts/uk/`
- Контекстная правка STT-ошибок (только в контексте фразы, без глобальных замен)
- Аудио → текст: `tools/transcribe_audio.py` + инструкции по Whisper, OpenAI API, AssemblyAI, Deepgram, Telegram, Descript, GigaAM, Vosk и др.
- Любая нейросеть: Cursor, VS Code, LM Studio, Ollama, OpenAI, Claude

### Быстрый старт

1. Откройте репозиторий в Cursor / VS Code
2. `inputs/raw_texts/` — или `inputs/audio/` → `python tools/transcribe_audio.py --install`
3. Скопируйте `prompts/ru/START_USER_PROMPT.md` в чат с ИИ
4. Результат: `output/books/*.docx`
